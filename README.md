> ### РЕАКЦИИ АНТИВИРУСОВ
> WinDivert иногда вызывает срабатывание антивирусной защиты.  
> Это средство перехвата и фильтрации трафика, необходимое для работы zapret.
> Подобный инструмент могут применять разные программы, в том числе вредоносные, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует компоненты WinDivert как инструменты повышенного риска или хакерские утилиты. Файл удаляется и помещается в карантин, а обнаружение обычно называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете, как правильно настроить исключения, предпочтительнее добавить исключение. Если нет, рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome найдите настройку "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
    * Пользователям роутеров Keenetic нужно активировать в настройках пункт "Транзит запросов". При отключенной опции Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг обычно не требуется.

4. Распакуйте архив в каталог без кириллицы и специальных символов в пути.

5. Запустите подходящий файл:
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для добавления стратегии в автозапуск используйте **`service.bat`** -> `Install Service` -> выберите нужную стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую**.

- [**`service.bat`**](./service.bat) - установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** - добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** - удаляет стратегию и WinDivert из списка служб.
  - **`Check Status`** - показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** - меняет режим обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения настройки стратегию нужно перезапустить.**  
  В скобках отображается её текущее состояние: включена или выключена.
  - **`IPSet Filter`** - управляет обходом сервисов из `ipset-all.txt`.  
  Опция полезна при диагностике ресурсов, которые без zapret открываются, а с ним работают неправильно.  
  Возможные состояния:
    - `none` - ни один IP не проверяется
    - `loaded` - IP сопоставляется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** - меняет текущий фейк на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загружает свежий `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым каналам Discord.</ins>
  - **`Check for Updates`** - вручную проверяет наличие новых версий.
  - **`Run Diagnostics`** - ищет распространённые причины неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент.
  - **`Run Tests`** - запускает проверку стратегий:
    - `Standard tests` - тестирует сайты из `utils/targets.txt`
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который виден на панели задач.  
Если процесс не запустился, обратитесь к [#522](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - В каталоге, который появится после запуска, откройте файл `hosts` в текстовом редакторе, запущенном от имени администратора.
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что файл действительно сохранился.

#### Работа не гарантирована. Если способ не помог, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/PennantBladeChaos/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Обнаружение стратегии может привести к тому, что вариант, работавший раньше, перестанет работать.
> В репозитории есть много стратегий обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте сообщения об ошибках.

- Проверьте, что нужный адрес присутствует в списках доменов или IP.

- Запустите другие варианты, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительные сведения приведены в [#765](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце выберите Y.
- Удалите старую папку zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа присутствует флажок разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска, исключив пробелы, специальные символы и кириллицу из пути.
- Запускайте разные скрипты `general`, проверяя доступ к нужным ресурсам. Если интернет-ресурсы не открываются, завершите программу через значок замка на панели задач и выберите другую стратегию.
- После нахождения рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`.

### Не работает игра или приложение при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### На Windows 7 требуется цифровая подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если выбранный ранее вариант перестал работать.
- См. также [#251](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение Discord после очистки.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею.
- Если сайт тоже недоступен, повторно проверьте все стратегии: на одном варианте YouTube может работать, а Discord - нет.
- См. также [#252](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/PennantBladeChaos/tg-ws-proxy).
- Также можно воспользоваться бесплатными MTProto-прокси, доступными в интернете.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Универсальная последовательность действий:
- через `service.bat` обновите ipset и активируйте `Game Filter`;
- если этого недостаточно, включите также `ipset any`.

Учтите: при `ipset any` многие сайты могут перестать открываться. Поэтому не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи от других игроков.

### Моей проблемы нет в списке

- Создайте обращение [здесь](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется;
- **`ipset-all.txt`** - IP-адреса и подсети;
- **`ipset-exclude-user.txt`** - IP-адреса и подсети-исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
